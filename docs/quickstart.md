# Quickstart

1. Install: `pip install ros2-doctor`
2. Source ROS: `source /opt/ros/humble/setup.bash`
3. `cd` to your colcon workspace root (contains `src/`)
4. Run `ros2-doctor doctor`
5. Follow printed fix commands
6. `ros2-doctor build` then `source install/setup.bash`
7. `ros2-doctor report -o report.md` to share diagnostics
